Create APK to release Android

1. Debug -> Release above top menu
2. click Android Project and right click -> Set as Startup Project
3. click Android Project and right click -> Properties -> Android Options -> Linking -> None
4. click Android Project and right click -> Archive... -> Distribute... -> Ad Hoc -> click 'plus(+)' icon -> Set Alias, Password, Confirm, FullName -> click created Signing Identity row & Save As -> save apk -> move the apk file to your android device & execute it
